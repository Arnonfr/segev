# segev
Website for the artist Segev (@segev_770): recycled metal sculpture and assemblage.
Static site (HTML/CSS/JS, no build step). Served via GitHub Pages.
- index.html - home with featured works
- works.html - all works in one grid; the centered label names the series in view and jumps between series
- about.html / exhibitions.html / contact.html
- assets/css/style.css - layout after olafureliasson.net/artworks, hover card after refikanadol.com/works
- assets/js/site.js - menu, series label, image blur-up, lightbox (prev/next, arrow keys)
- assets/works + assets/thumbs - curated artwork photos
Each work's hover-card colour is set inline (--card) from its photo. Fonts: Figtree and EB Garamond (Google Fonts).
All source photos live in Google Drive ("Segev - Artist Photos"). Instagram screenshots and face selfies are excluded from the site by decision of the site owner.
